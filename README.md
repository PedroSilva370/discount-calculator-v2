# Discount Calculator

A Python terminal application designed to calculate product prices with either discount or interest. The program includes input validation and a continuous execution flow, ensuring reliability and ease of use.

---

## Features

- Calculation of discounted prices  
- Calculation of prices with applied interest  
- Input validation to prevent runtime errors  
- Continuous execution for multiple calculations  
- Structured and modular code  

---

## How It Works

1. The program prompts the user to start  
2. The user inputs the product price  
3. The user selects:
   - `1` for discount  
   - `2` for interest  
4. The user enters the percentage value  
5. The program calculates and displays the result  
6. The user can choose to repeat the process
